# Rover lunar 3D

Web interactiva en Three.js con un modelo procedural aproximado de un rover lunar inspirado en una fotografia.

## Controles

- Flecha arriba: acelerar
- Flecha abajo: frenar o marcha atras
- Flecha izquierda / derecha: girar
- Arrastrar con el raton: mover la camara
- Rueda del raton: acercar o alejar

## Ejecutar en local

Desde esta carpeta:

```bash
php -S 127.0.0.1:8026
```

Despues abre:

```text
http://127.0.0.1:8026/
```

El proyecto usa Three.js desde CDN mediante import maps, asi que no necesita instalacion de dependencias.
